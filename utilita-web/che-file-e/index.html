Che file è?

Ti è arrivato un file che il telefono o il computer non sa aprire, senza estensione o con un nome come «allegato.dat»? Sceglilo qui: viene riconosciuto dal contenuto, non dal nome. Scopri che cos’è, con che programma si apre e scaricalo con l’estensione giusta.

Scegli il file

Qualsiasi file: un allegato, un download, un file senza estensione.

🔒Il file resta sul tuo dispositivo: viene letto dal browser e non viene caricato su nessun server.

  3. 3

Perché un file non si apre

Il telefono e il computer scelgono il programma guardando solo la fine del nome, l’estensione: .pdf va al lettore di PDF, .jpg alla galleria. Se l’estensione manca, è sbagliata o non la conoscono, si fermano e chiedono con che cosa aprire il file. Succede spesso con gli allegati della PEC, con i file scaricati da portali e gestionali, con le foto dell’iPhone e con i file passati attraverso chat o chiavette.

Il contenuto però non mente: quasi ogni formato comincia con una sequenza di byte fissa, una specie di firma. Questo strumento legge quei byte e, per i formati che sono contenitori, guarda anche dentro. Così distingue un Word moderno da uno ZIP qualsiasi, un vocale di WhatsApp da un altro audio, una fattura elettronica da un XML generico.

Attenzione ai programmi travestiti

Un file che dice di essere una fattura, un avviso di pagamento o una foto ma dentro contiene un programma (.exe, .scr, .js, un collegamento .lnk, un’app .apk) è il modo più comune per infettare un computer o un telefono. Lo strumento controlla il contenuto e avvisa quando il nome e il contenuto non corrispondono, e quando un documento di Office contiene macro. Nel dubbio non aprire il file e chiedi al mittente, con un altro mezzo, se te l’ha mandato davvero.

Le foto dicono dove sono state scattate

Le foto del telefono contengono spesso le coordinate GPS del luogo dello scatto, il modello del telefono e la data. Se nella foto ci sono, lo strumento lo segnala e ti porta a togliere posizione e dati prima di condividerla.

L’anteprima dei PDF usa pdf.js (licenza Apache 2.0) e l’apertura degli ZIP fflate (licenza MIT), entrambi serviti da questo sito.

Domande frequenti

Come fa a capire che file è se non ha estensione?+

Guarda il contenuto, non il nome. I primi byte di quasi ogni formato sono sempre uguali: un PDF comincia con «%PDF», uno ZIP con «PK», una foto JPEG con tre byte fissi. Per i formati che sono contenitori guarda anche dentro: un file Word moderno è uno ZIP con una cartella «word», un .p7m è una busta di firma con dentro il documento vero.

Il file viene caricato su un server?+

No. Il browser legge il file sul tuo dispositivo, in memoria: non viene inviato da nessuna parte e sparisce quando chiudi la pagina. Anche le librerie per l’anteprima dei PDF e per aprire gli ZIP sono servite da questo sito, non da servizi esterni.

Quali formati riconosce?+

Oltre cento: documenti (PDF, Word, Excel, PowerPoint, OpenDocument, EPUB, i vecchi .doc e .xls), firme digitali e PEC (.p7m, .p7s, .eml, daticert.xml), fatture elettroniche, foto e immagini (JPEG, PNG, HEIC dell’iPhone, WebP, TIFF, Photoshop), audio e video (MP3, vocali di WhatsApp, M4A, MP4, MOV, MKV), archivi (ZIP, RAR, 7z), programmi, caratteri, calendari, contatti, database e file di testo.

Perché dice che il file è un programma e non va aperto?+

Perché un trucco comune delle truffe è mandare un programma con un nome da documento, come «fattura.pdf.exe»: Windows spesso nasconde l’ultima estensione e il file sembra un PDF. Lo strumento guarda il contenuto e ti avvisa. Se non aspettavi un programma da quella persona, non aprirlo e cancellalo.

Che cos’è un file winmail.dat?+

È il modo in cui Outlook a volte spedisce gli allegati: dentro ci sono i file veri che il mittente voleva mandarti. Si aprono con programmi o app per file TNEF; in alternativa chiedi al mittente di rispedirli.

Si può aprire il file qui?+

Per PDF, foto, audio, video, testi e archivi ZIP sì: c’è un’anteprima, e dagli ZIP puoi estrarre un file alla volta. Per gli altri formati scaricalo con l’estensione giusta e aprilo con il programma indicato. Alcuni file, come PDF, foto e fatture elettroniche, si possono passare direttamente agli altri strumenti del sito.

Funziona senza connessione?+

Sì: dopo la prima visita il riconoscimento funziona anche offline. L’anteprima dei PDF e l’apertura degli ZIP, la prima volta che le usi, scaricano un componente dal sito, che poi resta sul dispositivo.

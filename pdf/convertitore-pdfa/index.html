Perché la Pubblica Amministrazione richiede il PDF/A?

Il formato PDF/A (Portable Document Format Archival) è un sottinsieme dello standard PDF ideato per garantire la conservazione a lungo termine dei documenti elettronici (ISO 19005). A differenza dei normali PDF, un file PDF/A deve essere completamente autocontenuto.

Requisiti di Conformità ISO 19005

Nessuna dipendenza esterna Tutte le fonti tipografiche e i caratteri devono essere incorporati nel file per evitare alterazioni visive su computer diversi.
Zero codice eseguibile Sono vietati script JavaScript e collegamenti esterni che potrebbero variare nel tempo o costituire rischi per la sicurezza.
Metadati XMP Standard Il file deve contenere lo schema XML strutturato richiesto dai portali ministeriali per una corretta indicizzazione.

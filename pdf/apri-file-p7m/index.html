Aprire un file P7M

Ti è arrivato un file che finisce in .p7m e il computer o il telefono non sa aprirlo? È un documento con firma digitale: dentro c’è il file vero, di solito un PDF. Sceglilo qui e scarica il documento, con l’elenco di chi l’ha firmato.

Scegli il file .p7m

Quello ricevuto via PEC o scaricato da un portale. Va bene anche un .p7m.p7m.

🔒Il file resta sul tuo dispositivo: viene elaborato dal browser e non viene caricato su nessun server.

Domande frequenti

Che cos’è un file P7M?+

È un documento con firma digitale in formato CAdES: una “busta” che contiene il documento originale (spesso un PDF, a volte un XML o un file Word) insieme alla firma e al certificato di chi ha firmato. Per leggerlo bisogna estrarre il documento dalla busta.

Perché il computer o il telefono non aprono il file .p7m?+

Perché l’estensione .p7m non dice che tipo di documento c’è dentro, e il sistema non sa a quale programma darlo. Questo strumento estrae il documento e te lo restituisce con la sua estensione vera, che si apre normalmente.

Il documento estratto ha ancora valore legale?+

Il valore legale sta nella busta firmata, cioè nel file .p7m: conserva quello. Il documento estratto è una copia da leggere, stampare o inoltrare, senza la firma.

Lo strumento verifica se la firma è valida?+

No. Mostra i dati scritti nel file (chi ha firmato, quando, chi ha emesso il certificato) ma non controlla la firma crittograficamente, né se il certificato era valido o revocato in quel momento. Per una verifica con valore legale usa un software di verifica della firma digitale, come quelli messi a disposizione gratuitamente dai certificatori.

Che cosa vuol dire .p7m.p7m?+

Che il documento è stato firmato più volte, una firma dentro l’altra: succede quando firmano due persone in sequenza. Lo strumento apre tutte le buste e mostra tutte le firme.

Il file viene caricato su un server?+

No. Il browser legge il file e ne estrae il documento sul tuo dispositivo, in memoria: non viene inviato da nessuna parte e sparisce quando chiudi la pagina. Questo strumento non scarica nemmeno librerie esterne: tutto il codice che serve è sul sito.

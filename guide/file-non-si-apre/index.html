Il file non si apre: estensioni, formati e allegati truffa

di Brian Barrionuevo · aggiornata il 27 settembre 2026 · 6 minuti di lettura

Un allegato che il telefono non sa aprire, un file che si chiama «download», una fattura in PDF che arriva da un mittente sconosciuto. Questa guida spiega come capire che cos’è davvero un file, come aprirlo e quando invece non va aperto, con esempi riconosciuti dal motore dello strumento «Che file è?».

In breve

  • Il sistema sceglie il programma dall’estensione; il contenuto dice che cos’è davvero il file, dai suoi primi byte.
  • Un «.pdf» che dentro è un programma, o un «.pdf.exe», è un allegato truffa: non si apre.
  • Le foto portano con sé posizione, data e telefono: prima di mandarle come file conviene togliere questi dati.

Perché un file non si apre

Il telefono e il computer scelgono il programma guardando solo la fine del nome, l’estensione: .pdf va al lettore di PDF, .jpg alla galleria, .docx a Word. Il contenuto non lo guardano. Per questo un file non si apre in quattro casi tipici:

  1. L’estensione manca o è sbagliata: file scaricati da portali e gestionali che escono come «download» o «documento.dat», allegati passati per chat e chiavette, nomi tagliati.
  2. Il formato non è supportato su quel dispositivo: le foto HEIC dell’iPhone su Windows, i file .p7m firmati digitalmente, i messaggi .eml, i documenti Pages o Numbers del Mac.
  3. Il file è incompleto o vuoto: un download interrotto, un allegato di 0 byte, un file ZIP troncato.
  4. Il file è protetto: un PDF con password di apertura, un archivio cifrato.

Nei primi due casi il contenuto è sano: basta capire che cos’è e dargli il nome o il programma giusto. Nel terzo il file va scaricato o richiesto di nuovo; nel quarto serve la password da chi l’ha mandato.

Il contenuto non mente: le «firme» dei formati

Quasi ogni formato comincia con una sequenza di byte fissa, una specie di firma: un PDF comincia sempre con %PDF-, una foto JPEG con i byte FF D8 FF, un archivio ZIP con le lettere PK, un programma per Windows con MZ. «Che file è?» legge quei primi byte, e per i formati che sono contenitori guarda anche dentro: così distingue un documento Word moderno da uno ZIP qualsiasi, perché anche i file .docx, .xlsx e .odt sono archivi ZIP.

Una volta rinominato con l’estensione giusta, il file si apre con un doppio clic. Il riconoscimento avviene nel browser: il file non viene caricato su nessun server, cosa importante quando si tratta di documenti personali.

I formati che creano più problemi

Per conservare un documento che deve restare leggibile negli anni servono formati aperti e stabili. L’allegato 2 delle linee guida AgID sui documenti informatici indica, formato per formato, se è adatto alla conservazione: PNG e CSV sì, JPEG solo per le immagini nate in JPEG, XML solo insieme al suo schema. Per i documenti impaginati il riferimento è il PDF/A, la versione del PDF pensata per l’archiviazione a lungo termine: contiene dentro di sé tutto quello che serve per mostrarlo uguale anche fra molti anni.

Allegati truffa: i trucchi più usati

Molte truffe via email e PEC puntano su un allegato che sembra un documento e invece è un programma. Aperto, può rubare password o installare un ransomware, che cifra i file del computer e chiede un riscatto. I trucchi ricorrenti:

  • La doppia estensione. Windows, per impostazione predefinita, nasconde le estensioni dei tipi di file conosciuti: «fattura_marzo.pdf.exe» appare come «fattura_marzo.pdf».
  • Il programma con il nome di un documento. Un file chiamato «bonifico.pdf» che dentro è un programma.
  • Le macro. Un documento Word o Excel che, appena aperto, chiede di «abilitare il contenuto»: le macro sono piccoli programmi, e abilitarle le esegue.
  • L’archivio compresso. Uno ZIP, a volte protetto da una password scritta nel messaggio, che contiene un programma: la password serve a non farlo esaminare dall’antivirus della posta.
  • La finta fattura di cortesia. Una PEC da un’azienda sconosciuta con oggetto «Emissione fattura» e un PDF «di cortesia» allegato: la Polizia Postale l’ha segnalata come veicolo di ransomware.

Esempio: due allegati controllati con «Che file è?»

  1. «fattura_marzo.pdf.exe»: Programma per Windows (EXE). Avviso: «Doppia estensione (.pdf.exe): Windows spesso nasconde la seconda, così un programma sembra un documento. Non aprirlo.»
  2. «bonifico.pdf»: Programma per Windows (EXE). Avviso: «Il nome dice .pdf ma dentro c’è un programma: è un trucco usato nelle truffe per far aprire un virus. Non aprirlo.»

In tutti e due i casi il nome dice documento e il contenuto dice programma: basta questo per non aprirli.

Che cosa fare

  • Se il mittente è sconosciuto, non aprire gli allegati e non cliccare sui link. Se è qualcuno che conosci ma il file non te lo aspettavi, chiedi conferma per un’altra via.
  • Diffida dei messaggi che mettono fretta o minacciano: multe, indagini, conti bloccati. Il nome del mittente si falsifica facilmente; conta l’indirizzo vero e il sito dove portano i link.
  • Fai vedere le estensioni dei file nelle impostazioni di Windows (Esplora file, «Estensioni nomi file»), così la doppia estensione si vede.
  • Se hai aperto qualcosa di sospetto, scollega il computer dalla rete, fai una scansione con un antivirus aggiornato e cambia le password da un altro dispositivo.
  • Segnala i messaggi alla Polizia Postale dal suo sito, il Commissariato di P.S. online.

Prima di mandare un file: che cosa si porta dietro

Anche i file innocui possono dire più di quanto sembra. Le foto del telefono contengono una scheda di dati chiamata EXIF, con la posizione GPS dello scatto, precisa a pochi metri, la data e l’ora e il modello del telefono: la foto di un oggetto messo in vendita, scattata in casa, può rivelare l’indirizzo. Le app di chat di solito tolgono questi dati quando comprimono la foto, ma se la mandi come file, per email o con un link a un archivio online, arriva l’originale con tutto quello che contiene.

Lo strumento «Togliere i dati nascosti dalle foto» mostra che cosa c’è in una foto e lo toglie senza ricomprimere l’immagine, nel browser. Per i documenti vale lo stesso principio: un file Word può conservare commenti e revisioni, un PDF il nome dell’autore; prima di mandarli fuori conviene controllare le proprietà del file, o esportare un PDF pulito.

Errori comuni

  • Rinominare un file a caso sperando che si apra: prima bisogna sapere che cos’è.
  • Fidarsi dell’icona: anche un programma può avere l’icona di un PDF.
  • Abilitare le macro di un documento arrivato per email da un mittente che non conosci.
  • Aprire l’allegato di un messaggio urgente o minaccioso senza verificare chi lo manda.
  • Pubblicare o vendere online foto scattate in casa senza togliere la posizione.

Domande frequenti

Come faccio a sapere che tipo di file è se non ha estensione?+

Dal contenuto: i primi byte di quasi ogni formato sono fissi. «Che file è?» li legge nel browser, senza caricare il file, e ti dice tipo, estensione giusta e programma per aprirlo.

Rinominare un file può danneggiarlo?+

No, il nome non cambia il contenuto. Ma dargli l’estensione sbagliata non lo fa aprire: serve quella del formato vero.

Un allegato PDF può essere pericoloso?+

Un file che dentro è davvero un PDF è di solito innocuo, ma può contenere link a pagine truffa. Il pericolo maggiore è il file che si chiama .pdf ma è un programma.

Perché le foto dell’iPhone non si aprono su Windows?+

Perché sono in formato HEIC, che Windows non sempre sa leggere. Si possono convertire in JPG, oppure impostare l’iPhone perché scatti direttamente in JPG.

Dove segnalo una email o una PEC truffa?+

Alla Polizia Postale, dal sito del Commissariato di P.S. online. Non rispondere al mittente e non aprire gli allegati.

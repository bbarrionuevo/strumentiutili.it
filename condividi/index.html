File ricevuti

Hai condiviso

    🔒I file restano nel tuo browser e si cancellano da soli entro un’ora.

    Che cosa vuoi fare?

    Nessun file in attesa.

    Da quando installi StrumentiUtili sul telefono (menu del browser → «Installa app» o «Aggiungi a schermata Home»), puoi mandargli un PDF, una foto, un vocale di WhatsApp o un file .p7m direttamente dal menu Condividi di qualsiasi app. Qui scegli che cosa farne: comprimerlo, unirlo, firmarlo, trascriverlo, aprirlo.

    Sul computer, con l’app installata, puoi aprire i file .pdf e .p7m con StrumentiUtili dal menu «Apri con».

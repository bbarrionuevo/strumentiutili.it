# \# StrumentiUtili.it — Suite di Micro-Strumenti Zero-Backend (Italia 2026)

# 

# \*\*StrumentiUtili.it\*\* è un ecosistema direzionale e un portale statico di micro-strumenti progettato per il mercato italiano (professionisti, PMI e cittadini). L'infrastruttura è costruita sul paradigma \*\*Zero-Backend (100% Client-Side)\*\*: non esistono database centralizzati né API esterne che processano i dati dell'utente. Ogni algoritmo matematico, validazione legale, elaborazione PDF e inferenza IA avviene esclusivamente nella memoria RAM/GPU del dispositivo locale.

# 

# \## 🛡️ Privacy by Design e Vantaggi Architetturali

# 

# \- \*\*Conformità GDPR (Art. 25):\*\* I dati finanziari, reddituali (ISEE, RAL, Mutui), sanitari e i documenti d'identità non abbandonano mai il browser. Nessun rischio di Data Breach (Zero-Upload Policy).

# \- \*\*Assenza di Data Processor:\*\* Non salvando dati sui nostri server, i professionisti legali e commerciali sono esonerati dalla stipula di DPA (Data Processing Agreements) previsti dall'Art. 28 del GDPR.

# \- \*\*Altissime Prestazioni e Offline-First:\*\* I calcoli avvengono in millisecondi. Grazie alla cache del Service Worker (`sw.js`), la suite è installabile come PWA e funziona in assenza di connettività internet.

# \- \*\*Algoritmia Avanzata:\*\* Implementazione nativa di metodi numerici (Newton-Raphson per il TAEG), algoritmi storici (Computus di Gauss per le festività), validazioni crittografiche ISO (Modulo 97-10 per IBAN) e visione artificiale (WebAssembly/WebGPU).

# \## ⚙️ Stack Tecnologico e Dipendenze Core

# 

# Il progetto evita framework frontend monolitici (come React o Angular) a favore di \*\*Vanilla JavaScript (ES6+)\*\* ultra-ottimizzato, garantendo caricamenti fulminei e un controllo capillare della memoria.

# 

# \- \*\*Interfaccia e Stile:\*\* HTML5 semantico, CSS tramite \*\*Tailwind CSS\*\* (compilato staticamente).

# \- \*\*Core Documentale:\*\* `pdf-lib` (Manipolazione binaria e PDF/A), `pdf.js` (Rendering in Canvas).

# \- \*\*Computer Vision e Biometria:\*\* `OpenCV.js` (WASM) per raddrizzamento prospettico; `MediaPipe` / `face-api.js` per il calcolo delle proporzioni cranio-facciali ICAO.

# \- \*\*Intelligenza Artificiale (Edge Computing):\*\* `Transformers.js` e `ONNX Runtime Web` interfacciati via \*\*WebGPU\*\* / \*\*WebAssembly SIMD\*\* per trascrizione e OCR.

# \- \*\*Crittografia:\*\* Implementazione esclusiva della \*\*Web Crypto API\*\* (`window.crypto.getRandomValues`) e parser ASN.1/PKCS#7 per la decodifica dei file .p7m (FatturaPA).

# \- \*\*Database Regolatori (Stateless):\*\* Le matrici dei comuni e le costanti fiscali 2026 sono ospitate in leggeri file JSON locali (`regole-fiscali-2026.json`), garantendo manutenzione centralizzata senza database SQL remoti.

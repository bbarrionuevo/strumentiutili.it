Cos'è una fattura elettronica e come viene letta in locale

I file XML e .p7m della fattura elettronica contengono i dati legali del documento: cedente/prestatore, cessionario/committente, dati generali, importi e righe di dettaglio. Lo strumento legge il file nel browser, estrae i contenuti XML e li rende in un formato chiaro e leggibile senza inviare alcun contenuto a server esterni.

Un file .p7m indica una fattura firmata digitalmente in formato PKCS#7: è un contenitore che mantiene la firma e la firma digitale del documento. In questo tool, la firma viene letta e il contenuto XML viene estratto direttamente sul tuo dispositivo, preservando la privacy totale.

FAQ

  • I file vengono caricati online? No. Tutto viene elaborato localmente nel browser.
  • Che cosa significa .p7m? È un file XML firmato digitalmente con PKCS#7, molto usato nel sistema di fatturazione elettronica italiano.
  • Posso stampare o salvare come PDF? Sì: il pulsante “Stampa / Salva in PDF” usa la stampa del browser per esportare il documento in PDF, nascondendo automaticamente i menu per un risultato pulito.
  • Il formato è ufficiale? L'anteprima è pensata per una lettura chiara e professionale, ma non sostituisce il documento originale XML firmato da Agenzia delle Entrate.
